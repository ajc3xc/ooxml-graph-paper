# Native DOCX corpus expansion and coverage audit v1

Status: investigation snapshot, 2026-08-29. The existing corpus is usable for a bounded
structural smoke/full comparison, but it is not yet a representative OMML stress corpus.

## What is actually present

The gold tree contains 127 DOCX packages:

| Tier/source | Documents | Interpretation |
|---|---:|---|
| Tier 1 hand-authored | 8 | Controlled fixtures for known graph and failure cases |
| Tier 2 OmegaUse/OfficeVal | 47 | Real-world Word-derived examples; source/privacy review required |
| Tier 2 DOCX benchmark, CC0 | 2 | Small but useful contractual-document pair |
| Tier 2 DOCX corpus/Common Crawl | 67 | Broad organic documents; provenance and representativeness vary |
| Tier 3 composite | 3 | Deliberately constructed multi-feature/adversarial cases |
| **Total gold** | **127** | 155 raw DOCX files exist under the raw data tree; 28 are not promoted into gold |

All 127 gold documents have a retained Word render status and retained PDF according to
the aggregate manifest. The gold manifests are independently extracted from OOXML and are
not generated by importing the Meridian product parser. This supports structural
independence, but not full human adjudication of every inferred edge.

## Native feature coverage audit

Counts below are direct ZIP/XML observations over the 127 gold DOCX packages, not claims
that every occurrence is semantically labeled correctly.

| Feature | Documents containing feature | Main limitation |
|---|---:|---|
| `w14:paraId` | 95 | 32 documents have no native paragraph IDs to test |
| OMML `<m:oMath>` | 7 | Only 8 equation containers total |
| OMML fractions | 3 | Basic fraction coverage only |
| OMML radicals | 2 | Radical edge cases are sparse |
| OMML subscript | 1 | No meaningful distributional coverage |
| OMML superscript | 1 | No meaningful distributional coverage |
| OMML n-ary operators | 0 | No organic n-ary coverage |
| OMML matrices/arrays | 0 | No matrix/array coverage |
| OMML accents/limits/multi-scripts | 0 | Unsupported/generalization claims cannot use this corpus |
| Tables | 114 | Strong table presence overall |
| `w:gridSpan` merged cells | 32 | Useful but not balanced by table type |
| `w:vMerge` vertical merges | 20 | Useful adversarial subset, still small |
| Explicit `w:tblGrid` | 70 | 44 documents lack it; this is valid OOXML and exposes parser assumptions |
| Bookmarks | 86 | Presence is high; semantic target/edge correctness needs review |
| Field/instruction text | 49 | Mixed fields; SEQ/REF/caption semantics need explicit classification |
| `w:ins` tracked insertions | 83 | `w:del` was not observed; revision coverage is one-sided |
| Headers/footers | 65 | Present, but not yet a balanced part-level gold stratum |
| Drawings | 85 | Image/shape semantics need separate annotation policy |
| Floating anchors | 52 | Useful for anchor tests; labels need relationship-aware review |

The aggregate manifests report 59 documents with non-zero uncertainty and 68 with zero
uncertainty. The uncertainty field is a useful review queue, not a validated probability.
The current graphs are therefore suitable for transparent exploratory and comparative
results, but claims about native graph fidelity should report uncertainty-stratified
results and not silently treat inferred edges as equally certain.

## Scientific consequences

1. The current 127-document corpus is adequate for text, paragraph identity, tables,
   merged-cell structure, fields, bookmarks, drawings, and parser robustness.
2. It is inadequate for a broad claim about OMML. The only defensible equation claim from
   the organic set is about the observed small subset, supplemented by clearly labeled
   hand-authored/composite adversarial fixtures.
3. The 32 no-`w14:paraId` documents must be excluded from paragraph-ID denominators, not
   scored as failures.
4. The 44 no-`w:tblGrid` documents must remain in the corpus: they are valid OOXML and a
   meaningful robustness test, not malformed-input exclusions.
5. Tracked revisions are not balanced because deletions are absent. Revision claims must
   remain `limited` until both insertion and deletion cases are available.
6. The source mixture overrepresents educational material, templates, and synthetic
   composites relative to long professional reports. This is acceptable for a bounded
   systems paper only if the source mix and per-stratum results are shown.

## Minimal expansion plan

Do not inflate the corpus indiscriminately. Add a targeted D1 suite of locally authored,
Word-rendered DOCX fixtures covering the missing native structures:

- n-ary operators with lower/upper limits;
- matrix and equation-array forms;
- accents, bars, boxes, enclosures, and delimiters;
- subscript/superscript/multi-script combinations;
- equations adjacent to punctuation, captions, fields, and numbered references;
- tracked insertion and deletion cases;
- headers/footers, floating drawings, bookmarks, hyperlinks, and content controls;
- nested tables, merged cells, omitted `w:tblGrid`, and split table rows;
- duplicate/missing/stale paragraph IDs and numbering collisions.

Each D1 fixture must retain the authoring recipe, raw DOCX hash, Word build, render PDF
hash, independent XML inspection output, and an explicit graph-manifest review record.
These fixtures test coverage and failure modes; they must not be presented as natural
corpus prevalence.

## Acquisition and annotation policy

- Keep the existing 127-document D0 manifest frozen for comparability.
- Keep all source bytes, derived PDFs, model files, and manifests on the local E: data
  root; do not redistribute third-party source packages.
- Treat ReadingBank and DocBank as layout/reading-order context tracks, not native graph
  gold, unless a true paired DOCX/OOXML source binding is established.
- Promote a new external document only after source URL/license, privacy screen, SHA-256,
  package-openability, render receipt, and document-level split assignment are recorded.
- Use a held-out document split. Never split pages from one document across train and test
  for any learned or tuned comparator.
- Human review is required for uncertain captions, references, source bindings, revisions,
  and equation semantics. A parser-generated manifest alone is not gold for those edges.

## Acceptance criteria for D1

D1 is sufficient for the Paper 1 functional study when every missing feature family above
has at least one independently inspected fixture, all fixtures render in Word, each has a
non-empty graph manifest, and the scorer reports per-feature denominators plus
`not_applicable`, `unknown`, and failure states. It is not necessary to obtain a huge new
corpus before running the bounded systems paper.
